# T3 — an admin can mark a parcel returned by hand (depends on T1)
An admin marks a parcel returned with `markReturned(parcelId)` in `src/admin.js`. It puts the parcel in the returned state, with the same effects as the carrier status.
## Acceptance criteria
- [ ] `markReturned(id)` sets the parcel state to `returned`.
- [ ] After `markReturned(id)`, the parcel's device is in `rma`, exactly as after a carrier return.
- [ ] Marking an already returned parcel changes nothing.
