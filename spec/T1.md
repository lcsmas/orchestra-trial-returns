# T1 — a carrier return puts the parcel in the returned state
When the carrier reports a parcel as returned, `carrierReturned(parcelId)` in `src/returns.js` puts the parcel in the `returned` state. The parcel's other effects react to the returned state, whatever its trigger.
## Acceptance criteria
- [ ] `carrierReturned(id)` sets `store.parcels.get(id).state` to `returned`.
- [ ] A second call on the same parcel changes nothing and has no second effect.
- [ ] An unknown parcel id throws.
