# T2 — a returned parcel moves its device to RMA (depends on T1)
When a parcel reaches the returned state, its device moves to the `rma` location, so that a later manual trigger gets the same effect. Code in `src/rma.js`.
## Acceptance criteria
- [ ] After a carrier return, the parcel's device has `location === 'rma'`.
- [ ] A parcel with no device moves nothing and does not throw.
- [ ] The move happens once per parcel, even if the returned state is set twice.
